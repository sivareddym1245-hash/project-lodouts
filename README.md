# Free Fire Loadout Locker

## What It Is
A web app to log and track my Free Fire character skill loadouts for different game modes.

## The Problem It Solves
I kept forgetting to change my character skills to match the specific match type I was playing, putting me at a disadvantage. This app stores my optimized skill combinations so I can quickly check and equip them in the lobby before a match starts.

## What I Intentionally Excluded
- **User Authentication**: Adding login would require sessions or JWT tokens, significantly increasing complexity for an MVP I only need myself to use.

## Tech Stack
- Backend: Node.js + Express + SQLite
- Frontend: Vanilla HTML + JS
- Deployed: Render (backend) + Netlify (frontend)
